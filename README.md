# 🐍 Python Data Structures — Day 5

Welcome to my **Day 5 Python Data Structures assignment**!

In this assignment, I practiced some of the most commonly used Python data structures and learned how to work with them through simple, hands-on coding exercises.

I completed the assignment using **Jupyter Notebook in Visual Studio Code (VS Code)** and uploaded the notebook to GitHub to keep track of my learning and progress.

## 📚 What I Learned

### 📋 Lists

I practiced working with Python lists and explored different operations such as:

* Creating and accessing lists
* Using indexing and slicing
* Finding the length of a list
* Iterating through a list using a `for` loop
* Adding elements with `append()` and `insert()`
* Combining lists using `extend()`
* Removing elements using `remove()`
* Sorting elements using `sort()`

### 🔤 Strings & Lists

I also practiced converting and manipulating strings and lists.

Some of the operations I worked with include:

* Using `split()` to convert a string into a list
* Converting words to lowercase
* Checking whether an element exists in a list using `in`
* Removing elements from a list
* Using slicing to select specific elements
* Using `join()` to convert a list back into a string

### 🔹 Sets

The assignment also introduced me to Python sets.

I practiced:

* Creating a set from a list
* Understanding how sets differ from lists
* Removing duplicate values
* Adding elements with `add()`
* Removing elements with `remove()`
* Checking the length and elements of a set

One interesting thing I learned is that **sets do not store duplicate values**, unlike lists.
